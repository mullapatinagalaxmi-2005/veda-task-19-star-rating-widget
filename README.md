# Veda Technology – Task 19: Star Rating Widget

## 📌 Project Overview

The Star Rating Widget is an interactive web application developed using HTML, CSS, and JavaScript. It allows users to select a rating from one to five stars and displays the selected rating instantly.

This project was developed as part of the Veda Technology Web Development Internship.

## ✨ Features

- Five clickable stars for rating selection
- Hover preview effect
- Displays the selected rating
- Different messages for each rating
- Reset Rating button
- Interactive and user-friendly interface
- Responsive design for mobile and desktop devices
- Keyboard focus support

## 🛠️ Technologies Used

- **HTML5** – Creates the webpage structure.
- **CSS3** – Styles the rating widget and star effects.
- **JavaScript** – Handles clicks, hover events, and rating updates.

## 🚀 How to Run the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if necessary.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Hover over the stars and click one to select a rating.
